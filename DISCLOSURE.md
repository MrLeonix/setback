# Hackathon Disclosure

Prepared for the Google "All Things Agentic Hackathon".

## Provenance of this repository

- This repository (`MrLeonix/setback`) was created on **2026-08-29**, inside
  the submission period for this hackathon.
- All code in this repository was written during the submission period.
  Zero lines were copied from any pre-existing repository, including prior
  scaffolding work by the same author.
- The multi-agent adversarial-review architecture (structurally disjoint
  Clause Reviewer and Evidence Reviewer, adjudication bench, and a
  deterministic citation gate before dispatch) is the author's own prior
  unpublished design practice, applied fresh to this codebase for this
  submission. No code implementing that design pre-dates the submission
  period.

## Data sources and licences

- **NSW ePlanning OnlineDA API** — CC-BY. Used to fetch Development
  Application metadata (applicant, description, exhibition dates, associated
  documents).
- **NSW Planning spatial services** (layerintersect and related ArcGIS
  endpoints) — CC-BY 3.0 AU, NSW Crown Copyright, NSW Department of Planning
  and Environment. Used to resolve zoning, height-of-building, floor-space
  ratio, and heritage layers for a given lot.
- **Council eTrack / ePathway exhibited documents** — statutorily public
  records under the NSW *Environmental Planning and Assessment Act 1979*.
  Used here for demonstration purposes with attribution to the originating
  council; not redistributed as a bulk dataset.
- **Google Maps Platform imagery** (Street View), where used as a fallback
  evidence source — subject to the Google Maps Platform Terms of Service,
  displayed with attribution. The Solar API and Aerial View API were
  evaluated and cut before shipping (no Australia coverage found in live
  testing); no code path in this repo calls either.

The live-validation story above (real DA fetch, real zoning resolution, real
overlay grounding) has been proven end-to-end against exactly one real DA to
date — Georges River Council, `PAN-661190` — not a portfolio of councils;
`ingest/`'s adapters are hardcoded to that council's and ePlanning's actual
response shapes (see README.md's Architecture section and
[docs/ARCHITECTURE.md](./docs/ARCHITECTURE.md) §8).

## AI-generated illustration (Veo)

The allowlisted demo case set — the two prior canonical cases plus the
founder's canonical film case (`1f4b7367fd30c089173ef09d7e8383a4`) — carry
one video clip on their Evidence tab, generated by `veo-3.1-generate-001`
(Vertex AI) from the real DA's own elevation drawing, illustrating the
overshadowing an objection describes. It is captioned "AI-generated
illustration — not evidence" wherever it appears and is structurally
excluded from the tribunal pipeline — it is never citable, never graded,
and never seen by either reviewer or the adjudicator. The clip was
generated once, offline, ahead of time (three `veo-3.1-generate-001`
generations were scored against a written rubric; the one that cleared
every axis was kept) at a one-time generation cost of US$1.60, and is
served as a static asset; the running app makes no on-demand Veo calls and
incurs no per-case generation cost. This US$1.60 one-time cost is now
disclosed directly on the Evidence-tab card itself ("Pre-generated with
Veo 3.1 · one-time cost US$1.60 · not part of this case's run cost"), not
just in this doc. See [README.md](./README.md#models-used) for the model
table entry.

## Build process

Beyond the AI models Setback calls at runtime (disclosed above), the
majority of this codebase was written by AI coding agents that the author
orchestrated directly, rather than by hand line-by-line — working in
strictly separated file lanes concurrently, with the author reviewing,
integrating, and deciding scope between rounds. Disclosed because it is the
most distinctive part of how this project actually got built in the time
available, not because the rules require it beyond the model-usage
disclosure above.
